# MouseSide V1.0 独立实现

需求依据：用户提供的《MouseSide 产品需求文档》，2026-10-14。
本分支 codex 采用 orphan 根提交，所有源代码、图标、构建脚本独立创建。

## 目标与范围

Windows 11 x64 原生 C++20 / Win32 桌面应用，免安装、离线、单进程。
第四按钮默认 Ctrl+V，第五按钮默认 Ctrl+C。提供八种预设、自定义快捷键录制、保留原始功能、禁用、暂停、托盘、INI 持久化、当前用户自启、单实例。
不实现 PRD 中 V1.1 及以后功能。关闭窗口隐藏到托盘，退出释放钩子。

## 设计

- UI：浅灰背景、白色圆角卡片、蓝色强调，两个按钮各有下拉选择和快捷键录制按钮。原生控件保留键盘导航和可访问名称；Per-monitor V2 DPI。
- Model：Action、Shortcut、Config 和 ButtonState。合法性、序列化、按下/松开状态机可单独测试。
- Config：严格验证每个字段，损坏字段恢复该字段默认。UTF-16 INI，写入同目录临时文件后原子替换；写失败显示错误，内存设置回滚。
- MouseHook：独立消息线程 WH_MOUSE_LL，回调仅做状态判断、复制映射及投递消息；按下一次投递一次，按下/松开成对吞掉。暂停中途切换也保持同一点击的处理方式。拒绝自身注入事件，队列失败时放行原始输入。
- KeyMapper：钩子线程的消息处理执行 SendInput，固定数组构建完整键盘序列。暂时释放多余修饰键，恢复用户持有状态；失败释放本程序可能注入的按键，并向 UI 报错。
- Recorder：仅录制期间安装 WH_KEYBOARD_LL，吞掉录制输入，避免 Win+D / Alt+Tab 激活系统行为；Esc 取消，修饰键单独按下不提交，保护快捷键拒绝；按键全部释放后卸载钩子。取消或失焦也清理。
- TrayUI：托盘正常蓝色、暂停灰色；Explorer 重启恢复图标。单实例采用 Local mutex + 专用窗口类及唤醒消息。重复启动只打开现有设置。自动启动参数 --background。
- 自启：HKCU Run MouseSideCodex 独立值，EXE 路径带引号；仅用户主动切换时修改，避免影响其他模型版本。
- 系统睡眠唤醒时通过一次消息重新安装钩子，无常驻轮询。

## 错误策略

钩子安装失败明确报错且原始鼠标行为可用；托盘失败显示设置窗口以提供退出入口；输入注入失败暂停映射并提示权限限制；配置无效恢复合法默认；记录实际自启状态。
常规权限运行，不请求提权。与高权限窗口、安全桌面、特殊游戏的限制写入 README。

## 验证与交付

CTest 检验默认映射、损坏 INI 恢复、配置落盘、点击状态机、注入事件、修饰键清理及快捷键合法性。Windows 集成测试验证真实 SendInput 接收、实际钩子处理、窗口关闭、单实例和后台启动。
提供 Release EXE、源代码、CMake 项目、README、默认 INI 及验证记录。无法自动切换真实蓝牙/2.4GHz 或执行睡眠的验收项明确标为人工待验。实际性能数字来源于本机测量，避免无依据承诺。
